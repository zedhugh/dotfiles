#+title: frps 安装与配置

在 Debian 系统上以官方发布的二进制安装 frp 服务端 frps（固定版本，
见 =vars/main.yaml= ），由 systemd 托管，服务保持启动状态。客户端
frpc 的部署不在本 role 范围内。

* 目录结构

- =/usr/local/bin/frps= ：frps 二进制，从 GitHub release 的压缩包中提取。
- =/etc/frp/frps.toml= ：主配置文件，由本 role 的
  =templates/frps.toml.j2= 渲染。
- =/etc/systemd/system/frps.service= ：systemd unit，由
  =templates/frps.service.j2= 渲染。
- =/var/log/frps.log= ：frps 日志（frps.toml 中的 =log.to= ）。

* 下载方式

压缩包的下载与解压在 /控制机本地/ 完成（缓存目录为本 role 下的
=tmp/= ，即 =frps_tmp_dir= ，与其他 role 的缓存隔离），再把 =frps=
二进制拷贝到目标机——目标机无需访问 GitHub。本地已有该版本的压缩包
时跳过下载与解压，直接复用。

* 变量

必填变量（无默认值，由引用方 playbook 提供，未提供时模板渲染报错）：

- =frps_bind_port=
- =frps_vhost_http_port=
- =frps_token=
- =frps_dashboard_port=
- =frps_dashboard_user=
- =frps_dashboard_password=

无默认变量。=vars/main.yaml= 是内部常量（版本、下载地址、缓存目录、
安装与配置路径），任务与 systemd unit 从那里取值，非配置项。

* 升级

修改 =vars/main.yaml= 中的 =frps_version= ，重跑 playbook 即可：新
版本压缩包会下载到本地缓存并解压，二进制变化会触发服务重启。跨
大版本升级先读官方 release notes 确认无破坏性变更，并同步检查
frpc 侧版本兼容（frp 要求两端版本匹配）。

* 注意

- dashboard 只监听 =127.0.0.1= （=webServer.addr= ），外网访问需经
  反代或 SSH 隧道。
- 安装的是固定版本二进制，不随 apt 更新，升级方式见上文。
