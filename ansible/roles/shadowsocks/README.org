#+title: shadowsocks-libev 安装与配置

在 Debian 系统上安装 shadowsocks-libev（发行版自带版本），用作
Shadowsocks 服务器，由 systemd 托管（unit 名 =shadowsocks-libev=
），服务保持启动状态。

* 目录结构

- =/etc/shadowsocks-libev/config.json= ：主配置文件，由本 role 的
  =templates/config.json.j2= 渲染。

* 变量

必填变量（无默认值，由引用方 playbook 提供，统一带 =shadowsocks_=
前缀，未提供时模板渲染报错）：

- =shadowsocks_mode= ：运行模式
- =shadowsocks_server_port= ：服务监听端口
- =shadowsocks_local_port= ：本地回环端口
- =shadowsocks_password= ：连接密码
- =shadowsocks_method= ：加密方法

无默认变量。

* 注意

- 安装的是 Debian 仓库中的版本，跟随发行版更新。
